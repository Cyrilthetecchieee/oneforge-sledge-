OneForge Sledge Documentation

            
Technical reference for the DESIGN.md format, CLI commands, and REST API.

          

        


        

          
1. What is DESIGN.md?

          

            DESIGN.md is a plain-text design system specification originally published by Google (Stitch project).
            It consists of structured YAML frontmatter at the top defining exact color hex values, typography scales,
            spacing tokens, and component definitions, followed by human- and AI-readable Markdown design rules.
          


          
2. Command Line Interface (CLI)

          
# Initialize starter DESIGN.md
sledge init

# Search library
sledge search "Stripe" --theme=light

# Safely extract and analyze live site
sledge analyze https://example.com

# Generate DESIGN.md
sledge generate https://example.com -o DESIGN.md

# Compare two design systems
sledge compare stripe.com linear.app

# Export tokens to CSS or Tailwind
sledge export stripe.com --format=css
sledge export stripe.com --format=tailwind

# Launch Web Dashboard
sledge serve --port=3456
