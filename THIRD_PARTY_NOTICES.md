## 3. DESIGN.md Specification Attribution

The `DESIGN.md` format and plain-text design system convention originated with Google's publication for AI-driven frontend synthesis (Stitch format). OneForge Sledge implements and extends this specification for machine-readable frontend token generation and autonomous coding agent interaction.

---

## 4. Model Context Protocol (MCP) Attribution

The Model Context Protocol (MCP) specification is an open protocol initiated by Anthropic for connecting AI models to external tools and data sources. OneForge Sledge's MCP server implements the JSON-RPC 2.0 specification over standard input/output (stdio) and HTTP streaming transports.
