# ONEFORGE SLEDGE — PRODUCT ROADMAP

**Product:** OneForge Sledge  
**Parent Brand:** OneForge  
**Category:** AI-Powered Design Intelligence Platform  

---

## 1. Vision & Trajectory

OneForge Sledge empowers human engineers and autonomous AI coding agents to discover, extract, engineer, and implement production-ready design systems with high fidelity and zero guesswork.

---

## 2. Release Milestones

### v1.0.0 (Current Release) ✅
- [x] Initial release of OneForge Sledge platform.
- [x] Core schema and Stitch-compatible DESIGN.md validation.
- [x] Multi-criteria design library discovery (query, category, theme, CIELAB $\Delta E$ color match).
- [x] Safe HTTP extraction pipeline with defensive anti-SSRF protections and robots.txt parsing.
- [x] Design Intelligence Engine (color clustering, modular typography scales, spacing grids, confidence scoring).
- [x] Multi-format token compilation (CSS variables, Tailwind, DTCG JSON, SCSS).
- [x] Differential design system comparison engine.
- [x] Model Context Protocol (MCP) server for Claude Code, Cursor, Codex, Windsurf, Antigravity.
- [x] Unified CLI executable (`sledge`).
- [x] High-density Web Dashboard Single-Page Application.

### v1.1.0 (Q1 2027) 📋
- [ ] Figma Token Sync: Direct import and bidirectional synchronization with Figma Variables and Tokens Studio.
- [ ] Headless Browser Add-on: Optional Playwright plugin for executing client-side Single-Page Applications behind heavy JavaScript hydration.
- [ ] Dark Mode Contrast Auditor: Automated WCAG AAA compliance checking across all surface steps.

### v1.2.0 (Q2 2027) 📋
- [ ] Component Code Synthesis: Automated generation of React (shadcn/ui compatible), Vue, and Svelte component stubs directly from extracted DESIGN.md files.
- [ ] Multi-page Site Crawling: Deep brand crawler capable of analyzing multi-page design token consistency across an entire domain.
- [ ] Team Library Cloud Sync: Team workspace collaboration and role-based access control for enterprise design system governance.
